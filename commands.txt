Ось покрокова інструкція з командами Git для виконання вашого завдання.

### 1. Створення копії проєкту (клонування)

Якщо у вас ще немає проєкту на комп'ютері, спочатку клонуйте його з віддаленого репозиторію (наприклад, GitHub або GitLab):

git clone <посилання_на_репозиторій>
cd <назва_папки_проєкту>


---

### 2. Створення гілки develop

Переконайтеся, що ви перебуваєте в основній гілці (зазвичай це main або master), а потім створіть нову гілку та перейдіть на неї:

# Перехід на основну гілку (про всяк випадок)
git checkout main 

# Створення нової гілки та перемикання на неї
git checkout -b develop


---

### 3. Збереження змін (коміт)

Після того, як ви внесли зміни у файли проєкту, додайте їх до індексу та зробіть коміт:

# Додавання всіх змінених файлів
git add .

# Створення коміту з описом
git commit -m "Початковий коміт у гілці develop"


---

### 4. Відправка (пуш) на сервер

Оскільки це нова гілка, її потрібно вперше "зв'язати" з віддаленим сервером:

# Відправка гілки на сервер та встановлення відстеження (upstream)
git push -u origin develop


Короткий підсумок команд:

1. git clone ... — завантажити проєкт.
2. git checkout -b develop — створити гілку develop.
3. git add . — додати зміни.
4. git commit -m "..." — зафіксувати зміни.
5. git push -u origin develop — відправити гілку на сервер.
